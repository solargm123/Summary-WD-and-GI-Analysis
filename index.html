ไม่ต้องสร้าง Project ระบบจะเปิดข้อมูลกลางล่าสุดให้อัตโนมัติ

Description · คู่มือหน้า Centerรวมความหมายสถานะ สิทธิ์ และขั้นตอนสำคัญไว้ในจุดเดียว

ขั้นตอนใช้ข้อมูลกลาง

1. Upload

Admin หรือ Editor เลือกไฟล์ FusionSolar หลายวันพร้อมกันได้

2. Merge

ระบบรวมข้อมูลตามโครงการและวันที่ รายการเดิมจะถูกอัปเดตโดยไม่สร้างงานซ้ำ

3. Open

เลือก Working Day, GI หรือ PR ได้ทันที ระบบเปิดข้อมูลกลางล่าสุดให้อัตโนมัติ

สิทธิ์ของผู้ใช้

Admin

จัดการได้ทุกอย่าง รวมสมาชิก สถานะงาน Backup และ Restore

Editor

สร้าง แก้ไข และบันทึกงานได้ ยกเว้นงานที่ Completed

Viewer

เปิดดูข้อมูลได้ แต่ไม่สามารถแก้ไขหรือบันทึก

ขั้นตอนทำงานแบบสั้น

1
สร้างหรือเปิดงานเลือก Working Day หรือ Global Irradiance จากหน้า Center
2
นำเข้าและตรวจข้อมูลอัปโหลดไฟล์ ตรวจเดือน โครงการ และค่าที่ผิดปกติ
3
บันทึกและตรวจสถานะรอคำว่า “บันทึกแล้ว” ก่อนออกจากหน้า หรือกดบันทึกด้วยตนเอง

ปุ่มสำหรับ Admin

System Check

Preview Restore

Restore Missing Data
