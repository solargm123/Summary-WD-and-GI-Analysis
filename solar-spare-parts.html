Recommended Workflow / ลำดับการใช้งานที่แนะนำ
ขั้นที่ 1
ตั้งค่า Master Dataเพิ่ม Category, Brand, Model, Location, Project และ Unit ให้พร้อมก่อนเริ่มลง Inventory
ขั้นที่ 2
เพิ่ม Inventoryเพิ่มอะไหล่ทีละรายการหรือ Import CSV แล้วตรวจ Category / Brand / Model ให้ตรงกับ Master
ขั้นที่ 3
ใช้ Movement เท่านั้นหลังตั้งยอดเริ่มต้นแล้ว ใช้ Receive / Issue / Reserve / Return / Repair เพื่อให้ History ต่อเนื่อง
ขั้นที่ 4
ตรวจ Dashboardเช็ก Low Stock, Out of Stock และรายการ Repair ก่อนทำงานประจำวัน
ขั้นที่ 5
Backup Workspaceสำรอง Workspace เป็น JSON ก่อนย้ายเครื่อง ล้าง Browser หรือแก้ข้อมูลครั้งใหญ่
Workspace Backup

Backup จะเก็บ Inventory, Master Data และ Movement ทั้งหมดไว้ในไฟล์เดียว เหมาะสำหรับย้ายเครื่องหรือกู้ข้อมูล

สำคัญ: Restore จะเขียนทับข้อมูลปัจจุบัน หลังยืนยันแล้วควรตรวจ Dashboard และ Data Health อีกครั้ง

Data Health Check
ตรวจความสัมพันธ์ระหว่าง Inventory, Master Data และ Movement
วิธีใช้ Master Data
  • Category ใช้แบ่งประเภทอุปกรณ์ เช่น Inverter, Electrical, Monitoring
  • Brand คือผู้ผลิต และ Model จะผูกกับ Brand เพื่อให้เลือกง่าย
  • Location ใช้ระบุคลังหรือ Site Stock และควรตั้งชื่อให้เป็นมาตรฐาน
  • Project ใช้กับการ Reserve / Issue เพื่อดูประวัติการใช้ตามโครงการ
  • หลีกเลี่ยงการสร้างชื่อซ้ำต่างกันเพียงช่องว่างหรือการสะกด เพราะจะทำให้ Filter แยกเป็นคนละรายการ
กติกา Stock Movement
  • Receive เพิ่ม Available
  • Issue ลด Available เมื่อเบิกออกจากคลัง
  • Reserve ย้าย Available → Reserved เพื่อกันของไว้
  • Repair ย้าย Available → Repair
  • Repair Return ย้าย Repair → Available หลังซ่อมกลับมา
  • ควรใส่ Project / Reference / Remark ทุกครั้งที่เป็นการเบิกใช้งานจริง เพื่อค้นย้อนหลังง่าย
