# Map overview: monthly GI / nearby comparison

Version: 20261002-map-peer20. Previous release: b79214e.

- Map dominates the layout; compact project list; details open only when selected.
- Each project marker shows monthly mean GI to 3 decimals, including available alarm readings. Month selection uses loaded dates, not the day filter.
- Compare within 20 km against at least 3 other independent coordinate sites. Same-coordinate phases count as one reference site; target site excluded.
- Per-day site median, then median across sites; compare averages over matching qualified dates only. Reference pool is all loaded GI projects, independent of display filters.
- Yellow: 10–20% below; red: more than 20% below; green: less than 10% below through 20% above; blue: more than 20% above; gray: insufficient evidence.
- Read-only overlay: no database migration, review changes, original alarm changes, or PR formula changes.
- Automated checks: HTML/JS syntax, mocked DOM/Leaflet integration and pure comparison regression tests. Live browser visual QA still required.
